### Introduction
This project is the R&DD analysis of the BBP Application. The idea is to create a system that solves the availability issues in biking paths. The user is able to register paths (both in Manual and Automated mode), record trips and search for the best one between a source and destination.

### Microservices architecture
The system uses advanced architectural models, such as Microservices. For each of the feature explained above, a single Microservice is mapped to. This promotes scalability, security and availability.

### BBP Application
The front-end of this application is a mobile app, downloadable from the App Store of choice. It uses Google Maps API to show the user maps informations. It also uses sensors to capture data from the outside world, while also receiving notifications after the registration of the path

### Neo4j GDBMS
An important feature to notice is the use of a GDBMS for the retrieving of the paths information

### Possible improvements
-Improve flexibility by adding the possibility of recording a trip and a path at the same time
